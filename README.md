
## Cara menambah proyek
Buka `script.js`, tambahkan objek baru di array `PROJECTS`, lalu isi link `repo`, `demo`, atau `laporan`.
Isi juga link GitHub/Instagram/Email di array `CONTACTS`.

## Cara membuat website bisa dilihat semua orang (gratis, GitHub Pages)
1. Buat akun di https://github.com
2. Klik **New repository**, beri nama misalnya `portfolio`, pilih **Public**.
3. Klik **uploading an existing file**, unggah semua isi folder ini (`index.html`, `style.css`, `script.js`, folder `assets`, dan `README.md`), lalu **Commit changes**.
4. Buka **Settings → Pages**. Pada *Source* pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
5. Tunggu 1–2 menit. Alamat websitemu: `https://USERNAME.github.io/portfolio/`
   (agar alamatnya `https://USERNAME.github.io`, beri nama repository `USERNAME.github.io`).

Alternatif gratis lain: Netlify Drop (https://app.netlify.com/drop), tinggal seret folder ini ke halamannya.
